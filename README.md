## How the site is built

- A single static file, `index.html`, with HTML, CSS and JavaScript inline.
- No frameworks or build step.
- Architecture diagrams are generated as inline SVG.
- The 3D cube is pure CSS.
- Light and dark themes, a responsive layout and a print-friendly CV view.

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in any browser.

## Deploy with GitHub Pages

1. Name the repository `YOUR-USERNAME.github.io`.
2. Go to **Settings**, then **Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
4. The site goes live at `https://YOUR-USERNAME.github.io` in a few minutes.
